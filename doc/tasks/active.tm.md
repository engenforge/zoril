- [ ] +safety +tests +AI-D Z-0060 B1.4 `Vec.extend_from_slice` stores frame views its summary does not record
    > **Created:** 2026-11-05 **Found by:** Z-0049 (Lead L) and its review. **Check-in:** stop for review after it. A hole open in both modes.

    - **Now:** `Vec<T>.extend_from_slice(self, slice: [T])` (`stdlib/vec.zrl`) copies `T` elements with `memcpy` and declares no `#[stores]`, so neither the old rules nor `--provenance` see that the elements of `slice` are stored into `self`.    
    ```zoril
    import "vec.zrl";
    use vec::Vec;
    fn fill(out: &mut Vec<[u8]>) {
        let buf = [42 as u8; 16];
        let s: [u8] = &buf;
        let views = [s];
        out.extend_from_slice(&views);
    }
    fn clobber_stack() -> u8 { let arr = [77 as u8; 64]; return arr[0]; }
    fn main() -> i32 {
        let mut v: Vec<[u8]> = Vec.new();
        fill(&mut v);
        let c = clobber_stack();
        return v[0][0] as i32 + (c as i32) * 0;
    }
    ```
