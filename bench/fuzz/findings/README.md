# The findings record

A finding is a program whose Rust twin disagreed with Zoril. It is minimised - lines deleted, both oracles re-run, until it is small - and then filed here as a pair: `<name>.zrl` and its `<name>.rs` twin.

The fuzzer writes here only when the run says where the record is (`--record-findings`, `--findings DIR`, or `FUZZ_FINDINGS`). A run that says nothing copies nothing, which is what keeps a test run's own scratch out of this directory: the self-tests' stub compiler accepts every mismatch shape on purpose, and 30 pairs that were never findings were once left here by a run nobody could redirect.

**Every pair in this directory is named below.** `--reverify` re-runs each pair against both oracles and reports whether it is still open, fixed, or was never a disagreement; it fails on a pair this file does not name, on a pair it cannot classify, and on a pair still open. `scripts/check_fuzz_record.sh` (the `fuzz-record` gate in `make test`) pins that behaviour and checks this directory too.

None are stored: the three finds the fuzzer has raised are fixed, with the program of each pinned as a test. The first - a borrow accepted where an owned `Box` is expected, which let the callee free memory the caller owned - is pinned by `tests/error_reporting/err_box_{borrow_passed_as_owned,moved_into_borrow,arena_consumed_as_borrow}.zrl` plus probe 178. The second - a write through a `&mut` that ended that reference's own borrow, which segfaulted with a `Drop` value - is pinned by four error tests, probe 179 and mutation M119. The third - a bare block statement followed by `*r = 5`, parsed as `({ }) * r = 5`, which lowered unit times a pointer with `NO_SSA` as an operand and stored through a wild address - is pinned by `tests/language/memory/write_through_mut_after_inner_block.zrl` (the minimised form, exit 5), `write_through_mut_after_inner_block_drop.zrl` (the original program, exit 1), probes 221-228 and `tests/zilc/{undefined_operand,store_non_pointer_address}.zil`. The one shape that is still a difference from Rust is not a finding but a decision: `../intended_differences.txt` carries the bare read through a live `&mut`, with the measurement that says why the accepted spelling is accepted and a date to re-measure it. See `../README.md` for the blind calibration that found the first two.
